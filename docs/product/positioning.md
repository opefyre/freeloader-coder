# Product positioning

## Audience

GitHub-capable vibecoders who can clone a repository, run documented commands,
connect accounts or API keys, inspect diffs and tests, and make product
decisions—but do not want to design or operate a multi-model development
platform.

## Category and promise

Pipeline Studio is a **free-first autonomous development operations plane**.
It coordinates provider capacity and local workers through grounded task
graphs, deterministic validation, independent review, recovery, and evidence.

The concise promise is:

> Reliable autonomous development, without a surprise AI bill.

## Differentiation

- OpenCode centers a flexible coding-agent experience across terminal, desktop,
  and IDE surfaces with broad model access.
- OpenHands centers a composable software-agent platform with SDK, CLI, local
  GUI, cloud, and enterprise paths.
- Aider centers AI pair programming inside a local Git repository.
- Pipeline Studio centers durable orchestration and operations across multiple
  providers and workers: task dependencies, cost admission, checkpoints,
  deterministic checks, independent review, healing, evidence, and operator
  decisions share one state model.

These are different centers of gravity, not claims that competing products are
inferior. Current official sources:

- <https://opencode.ai/docs/>
- <https://docs.openhands.dev/overview/introduction>
- <https://docs.openhands.dev/sdk/index>
- <https://aider.chat/docs/>

## Claims we will not make

- “Free forever” or “unlimited”; external allowances can change.
- “Fully autonomous”; consequential decisions and unresolved uncertainty still
  need an operator.
- “Always secure,” “private,” or “production ready.”
- “Better code than every coding agent or model.”
- Benchmark, user-count, savings, or reliability claims without current,
  reproducible evidence and a defined comparison.

## Name

“Pipeline Studio” is the public product name for this repository. “Freeloader
Coder” remains an informal repository-era descriptor and is not the primary
market name. Revisit the name before trademark registration or a commercial
offering.
