# Control Center

The Control Center projects canonical pipeline state into current health, historical performance, and configured capacity. Every value retains source events, scope, observation time, freshness, aggregation, and estimation status. Missing and stale evidence remain explicit and never become zero.

Provider execution share includes successful and failed external and local calls inside the selected range. Visual elements link to exact tasks, evidence, commits, Jira work, and provider dashboards.

Operator controls are state-valid and idempotent. Pause, resume, retry, repair, reprioritize, and escalate first preview the active lease, preserved work, dependencies, cost, approval need, and postcondition. Quarantined work cannot be resurrected without explicit evidence review.

Local doctor checks cover database, services, workers, models, providers, connectors, disk, permissions, validators, and updates. Support bundles are opt-in and previewable. Source code, prompts, credentials, secrets, and user paths are excluded or redacted by default; correlation and reproduction context remain.
