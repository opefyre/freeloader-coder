# Security policy

Do not report vulnerabilities in public issues or Discussions. Use
**Security → Advisories → New draft security advisory** in this GitHub
repository.

Include the affected version, observable impact, minimal reproduction, and any
suggested mitigation. Do not include live credentials, unrelated source,
personal data, health data, or financial data. Revoke any credential that may
have been exposed.

Supported versions and response expectations will be published with the first
public release. Until then, reports against the current `main` branch are
accepted on a best-effort basis.
