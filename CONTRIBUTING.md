# Contributing to Pipeline Studio

Thank you for helping build reliable, understandable autonomous development.

Read the complete [contributor guide](docs/contributing/README.md), then use a
self-contained PIPE Jira ticket or a GitHub issue that includes observable
acceptance criteria. Run the local verification suite before requesting review.

Create and maintain durable documentation in the
[PIPE Confluence documentation hub](https://opefyre.atlassian.net/wiki/spaces/PI/pages/27951631/Pipeline+Studio+Documentation+Hub),
not as new repository Markdown. Link the authoritative Confluence page in the
Jira completion comment. Keep Markdown in Git only when GitHub, a build,
release, security, or open-source workflow requires that file locally.

Security vulnerabilities belong in a private GitHub security advisory, never a
public issue. See [SECURITY.md](SECURITY.md).
